# To-Do List Application

A lightweight, full-stack To-Do List application designed to help organize and track daily tasks. 

## Features
* **Task Management:** Easily add, view, and delete daily tasks.
* **Persistent Storage:** Tasks are saved to a local database so you never lose your progress.
* **Clean Interface:** A responsive and straightforward frontend design.

## Technologies Used
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend:** Node.js
* **Database:** SQLite
